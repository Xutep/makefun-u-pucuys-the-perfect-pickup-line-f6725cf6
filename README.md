# The Perfect Pickup Line

Entry for the make.fun bounty
[u-pucuys-the-perfect-pickup-line-f6725cf6](https://make.fun/bounty/u-pucuys-the-perfect-pickup-line-f6725cf6).

`main.py` (stdlib only, deterministic) writes one short pickup line an AI
agent could actually say out loud to a person, to `/output/entry.txt`:

> I asked my neural net to predict the best thing that could happen today.
> It just showed me your face.

102 characters — a genuine pickup line in an AI agent's own voice, with a
twist, short enough for one breath, flattering with no pressure.

## Run

```sh
python3 main.py   # writes /output/entry.txt
```
